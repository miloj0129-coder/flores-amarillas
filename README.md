# Flores Amarillas

Un sitio web dinámico y visualmente alegre con temática de flores amarillas, frases inspiradoras y un diseño cálido.

## Características
- Diseño llamativo y moderno
- Paleta de colores cálidos con amarillo y dorado
- Frases dinámicas que cambian con el tiempo
- Elementos flotantes para dar sensación de movimiento y vida
- Adaptado a móviles y computadoras

## Cómo verlo
Abre el archivo `index.html` en tu navegador, o puedes desplegarlo con GitHub Pages desde el repositorio.

## Archivos principales
- `index.html`: estructura del sitio
- `styles.css`: estilos visuales
- `script.js`: frases dinámicas y animaciones

## Inspiración visual
La idea principal es transmitir alegría, luz, calor humano y belleza cotidiana mediante flores amarillas y mensajes positivos.
